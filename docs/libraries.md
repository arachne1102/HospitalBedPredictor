# 필수 라이브러리

프로젝트의 현재 단계와 향후 계획에 따라 필요한 라이브러리를 정리하였습니다.

## 데이터 수집 단계

### 1. mysql-connector-python
- **역할:** Python과 MySQL 데이터베이스를 연결합니다.
- **사용 부분:**
  - 데이터베이스 연결 및 쿼리 실행: MySQL에서 데이터를 조회하고 가져옵니다.

### 2. sshtunnel
- **역할:** SSH 터널링을 통해 원격 서버와의 안전한 연결을 지원합니다.
- **사용 부분:**
  - 원격 데이터베이스에 보안 연결: SSH를 활용하여 원격 서버와의 통신을 설정합니다.

### 3. python-dotenv
- **역할:** 환경 변수 관리를 도와줍니다.
- **사용 부분:**
  - `.env` 파일에서 설정을 불러와 안전하게 환경 변수를 관리합니다.

---

## 데이터 처리 및 분석

### 4. pandas
- **역할:** 데이터 처리 및 분석의 핵심 라이브러리입니다.
- **사용 부분:**
  - 데이터 로딩 및 전처리: CSV 파일, 데이터베이스에서 데이터를 불러와 `DataFrame` 형태로 관리하고 전처리합니다.

### 5. numpy
- **역할:** 고성능의 수치 계산 및 배열 연산을 제공합니다.
- **사용 부분:**
  - 수치 연산 및 데이터 변환: 복잡한 배열 연산과 통계 계산 수행.

---

## 모델링 및 예측

### 6. scikit-learn
- **역할:** 머신러닝 알고리즘과 데이터 전처리 도구를 제공합니다.
- **사용 부분:**
  - 데이터 전처리: 스케일링, 인코딩 등.
  - 모델 구현 및 평가: 머신러닝 모델 학습 및 성능 평가.

### 7. statsmodels
- **역할:** 통계적 모델링과 시계열 분석 도구를 제공합니다.
- **사용 부분:**
  - 시계열 분석 및 통계 모델링: ARIMA와 같은 통계 모델을 사용하여 데이터 분석.

### 8. Prophet
- **역할:** 시계열 예측을 위한 라이브러리입니다.
- **사용 부분:**
  - 추세와 계절성을 고려한 시계열 예측: 예측 모델 구현 및 분석.

---

## 시각화

### 9. seaborn
- **역할:** 고급 데이터 시각화 도구를 제공합니다.
- **사용 부분:**
  - 결과 시각화: 분석 및 예측 결과를 효과적으로 표현.
  - **참고:** 설치 시 Matplotlib도 함께 설치됩니다.

---

## 딥러닝 및 최적화

### 10. tensorflow
- **역할:** 딥러닝 모델을 구축하고 학습합니다.
- **사용 부분:**
  - LSTM 모델 구현: 복잡한 시계열 패턴을 학습하여 예측 정확도를 향상.
  - **참고:** TensorFlow 2.x는 Keras와 통합되어 추가 설치가 필요 없습니다.

### 11. Optuna
- **역할:** 하이퍼파라미터 최적화를 지원하는 도구입니다.
- **사용 부분:**
  - 모델 성능 개선: 최적의 하이퍼파라미터를 탐색하여 예측 정확도를 향상.
  - **참고:** 자동화된 하이퍼파라미터 튜닝 도구로, 성능 최적화에 사용됩니다.

---

```bash
pip install -r requirements.txt
